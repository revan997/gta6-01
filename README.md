A GTA VI–inspired open-world chase game set in Solmar Bay, a Vice City–style
harbour city: four wanted stars, a police helicopter overhead, and a crew
that never lets the heat win. Drive the Solmar GT along the waterfront,
steal the Palm Coupe, break through the roadblock, and meet Dante at the
harbour as the sun goes down over the Bay.

## How to play

- **WASD** — drive / steer
- **Space** — brake
- **P** — pause / resume
- **R** — switch radio station

Four chapters, four staged moments: the cover chase, the waterfront combat,
the stolen-vehicle pursuit, and the golden-hour harbour heist.

## Run locally

```sh
node serve.ts --port 8080
```

Then open <http://localhost:8080>.

## Tech

Three.js, hand-built procedural city: lagoon + basin water, Deco Tower,
marina signs, traffic, pedestrians, police AI with helicopter, missions,
radio, save games (localStorage), and a real minimap.
